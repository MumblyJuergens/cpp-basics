# cpp-basics

A few basic files I always seem to need with a C++ project

These are unlikely to be of much use to anyone but me.

Obviously cmake-kits.json is specific to normal ass Linux system and not useful for every system.

.clangd is just to stop specific annoying errors when using clangd and gcc in nvim.

cmake/helpers.cmake is out of date, but FullCompilerWarnings is super useful for turning on nutloads of warnings.
